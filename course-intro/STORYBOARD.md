## Decisions

- Spine: one paper sheet. Every card is drawn on it. When the camera returns, it sits in the same centered 1280×720 plate.
- Held frame: 05 — Dive in. The closer lands, then the face holds.
- Voice: the original take, start to end. Music: none.
- Captions: none in this cut, so type may use the full frame.
- Bans: no cyan, glow, gradient text, neon, upscaled face, invented name, fake code editor.
- Motion failures to avoid: a slideshow of unrelated cards, and decoration that does not teach the beat.
- Brand: paper `#FFFCF2`, ink `#252422`, stone `#403D39`, muted `#CCC5B9`, accent `#EB5E28`. Display Marker Felt, body Iowan Old Style, kicker IBM Plex Mono. Tokens live in `frame.md`.
